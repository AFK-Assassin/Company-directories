# Company Directory

A modern and responsive **Company Directory** web app built using **React.js** and **Tailwind CSS**.  
It allows users to browse, search, and view company profiles in an elegant and interactive UI.

## Features

- View list of companies with essential details  
- Search and filter companies by name or category  
- Responsive UI with Tailwind CSS  
- Fast and dynamic rendering using React hooks  

#    Tech Stack

**Frontend:**
- React.js (Vite)
- Tailwind CSS
-  React Icons (for icons)

**Version Control:**
- Git & GitHub

**Deployment:**
- Netlify (https://zunaiddirectory.netlify.app/)
